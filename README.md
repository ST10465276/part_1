# Brief description of the system
Race_Day is an full-stack web-based event management system created for events such as Soweto Marathon. It involves two main users which are the organisers who creates,updates and deletes these events using the category which these events belong too, they also capture the participants' results. Participants create a user profile, browse events, enter event by selecting a category and tracking their enrolment in the event.

The planning for this system is divided into three parts:
-Entity Relationship Diagram(ERD)
-API Endpoint Plan
-SQL Database query
